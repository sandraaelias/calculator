# Calculator

A simple calculator built with vanilla HTML, CSS, and JavaScript.

## Built With

- **HTML** — markup and structure (`index.html`)
- **CSS** — styling and layout (`style.css`)
- **JavaScript** — calculator logic and button interactivity (`script.js`)

## Features

- Basic operations: addition, subtraction, multiplication, division, percentage
- Clear (`AC`) and delete last character (`DEL`)
- Decimal point support

## Usage

Open `index.html` in a browser to use the calculator.
